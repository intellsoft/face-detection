# 👁️ ابزار پیشرفته تشخیص چهره

**نرم‌افزار مبتنی بر هوش مصنوعی برای شناسایی چهره در ویدیوها با قابلیت‌های تعاملی**

![Advanced Face Detection Tool](https://lh3.googleusercontent.com/d/1fvhaaOt90ssTWTIjbZpX0k4CwkBbS_UB)

## ✨ ویژگی‌های اصلی
- 🎥 پخش هوشمند ویدیو با قابلیت تمام‌صفحه
- ⏱️ پرش به زمان مشخص در ویدیو با کلیک روی تصویر
- 📸 ذخیره خودکار فریم‌های حاوی چهره
- 🖼️ گالری تصاویر با پیش‌نمایش و برچسب زمانی
- 🚀 پردازش سریع با استفاده از **YOLOv8** و پشتیبانی از GPU

## 🚀 کاربردها
- تحلیل ویدیوهای نظارتی برای شناسایی افراد
- استخراج فریم‌های حاوی چهره از فیلم‌ها
- نظارت بر حضور افراد در محیط‌های مختلف
- تحقیقات امنیتی و پزشکی قانونی
- ساخت بانک اطلاعاتی چهره‌ها

## 📝 راهنمای شروع سریع
1. نرم‌افزار را اجرا کنید
2. ویدیوی مورد نظر را انتخاب کنید
3. دکمه «شروع پردازش» را بزنید
4. نتایج را در گالری بررسی کنید
